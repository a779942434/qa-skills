# 造前置测试数据（主数据）

测试「订单周期定义表（OSD）」等 MES 功能前，需要先造主数据。常用三个页面，按依赖顺序造：

产品 → 工艺路线（含工序）→ 产品 BOM。

## 页面地址（欧斯达 t-ousida）

- 产品信息定义：`/master-data/product/product-message-definition/index`
- 工艺路线定义：`/master-data/technology/process-route-definition/index`

## 1. 产品信息定义：新增产品

1. 左侧产品系列树：先点「成品(CPXL003)」展开，再点目标系列（如「半成品(CPXL002)」）。
2. 点顶部「新增」。
3. 弹窗有 15 个字段，**只填 产品名称 + 产品编号**，其余用默认值即可。
   - 用表单项索引定位：产品名称 = `el-form-item` 第 2 个（idx1），产品编号 = 第 4 个（idx3）。
   - 「产品系列名称」会自动带出（显示类似「成品 / 半成品」路径）。
4. 点「确定」，toast「新增成功」。

## 2. 工艺路线定义：新增工艺路线 + 工序

1. 点顶部「新增」：主表只填 **产品名称（下拉）+ 工艺路线**。
2. **点击主表行**，下方出现「工序」子表。
3. 子表「新增」（页面第 2 个「新增」按钮）：只填 **工序（标准工序下拉）+ 工序顺序**。
   - 工序下拉选项形如「注塑(BZGX001)」「装配(BZGX023)」。
4. 点「确定」，toast「新增成功」。

## 3. 产品信息定义：新增产品 BOM

1. 在产品信息定义点开目标产品系列，**点击产品行**，详情面板出现多个子表。
2. 找到「产品BOM定义」子表（表头含「bom产品 / 母件产出量 / 子件消耗量」）。
3. 点该子表「新增」（页面第 2 个「新增」按钮）。
4. 必填：**bom产品（下拉选组件产品）+ 母件产出量 + 子件消耗量**。
5. 点「确定」，toast「新增成功」。

## 造数要点

- 命名带清晰测试标识（如 `测试产品-QA0818`、`测试工艺QA`），便于搜索、筛选、清理。
- 「点击主表行出现子表」是这套系统的通用交互（工艺路线定义、产品信息定义 BOM 都用）。
- 「新增」按钮有多个（主表 + 各子表），子表新增通常是第 2 个 `button:has-text('新增')`。
- 清理顺序按依赖倒序：订单周期定义表记录 → 产品 BOM/工艺路线（子）→ 产品（父）。
