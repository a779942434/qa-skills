## 单据审核类

适用：ECN、工单、计划等单据审核流。

1. 筛选区：每个筛选项一条用例 + 多条件组合
2. 主表：新增 / 编辑 / 删除、字段校验、唯一性
3. 审核流：审核 / 取消审核、二次确认、状态流转、编辑权限锁定
4. 子表：子表新增编辑、主审子锁、字段自动带出
5. 外跳转：带参跳转、默认查询、反向业务流

## 排产拆分类

适用：拆单、SMT 排产、计划生成等。

1. 前置校验链：按流程图顺序逐个校验节点（产线 → 工艺 → 设备）
2. 生成规则：不同类型（单 / 双面板、数量 / 百分比）分别拆用例
3. 原单规则：原单是扣减、复用还是作废，数量 / 状态分别校验
4. 新单规则：编号生成、字段继承、初始状态、独立操作性
5. 批量操作：批量成功、部分成功部分失败、全失败

## 权限校验类

适用：岗位技能、数据权限等。

1. 层级校验：从上到下逐层验证（岗位 → 设备 → 产品）
2. 分支场景：有计划 / 无计划、具体 / 通用、单产品 / 多产品
3. 优先级：具体优先于通用，高维度优先于低维度
4. 触发时机：登岗触发、切换触发、每次操作必触发
5. 提示交互：弹窗文案、关闭方式、附加入口

## 查询报表类

适用：物料钢网、库存、报工等查询报表。

1. 筛选区：每个筛选项的数据源、多选 / 单选、默认值
2. 表格属性：是否可编辑、是否支持新增
3. 字段取值：每个字段的来源表、计算逻辑、显示格式
4. 排序分页：排序规则、分页功能
5. 导出：所见即所得、筛选后导出
