## 单据审核类

适用：ECN、工单、计划等单据审核流。

1. 筛选区：每个筛选项一条用例 + 多条件组合
2. 主表：新增 / 编辑 / 删除、字段校验、唯一性
3. 审核流：审核 / 取消审核、二次确认、状态流转、编辑权限锁定
4. 子表：子表新增编辑、主审子锁、字段自动带出
5. 外跳转：带参跳转、默认查询、反向业务流

## 排产拆分类

适用：拆单、SMT 排产、计划生成等。

1. 前置校验链：按流程图顺序逐个校验节点（产线 → 工艺 → 设备）
2. 生成规则：不同类型（单 / 双面板、数量 / 百分比）分别拆用例
3. 原单规则：原单是扣减、复用还是作废，数量 / 状态分别校验
4. 新单规则：编号生成、字段继承、初始状态、独立操作性
5. 批量操作：批量成功、部分成功部分失败、全失败

## 权限校验类

适用：岗位技能、数据权限等。

1. 层级校验：从上到下逐层验证（岗位 → 设备 → 产品）
2. 分支场景：有计划 / 无计划、具体 / 通用、单产品 / 多产品
3. 优先级：具体优先于通用，高维度优先于低维度
4. 触发时机：登岗触发、切换触发、每次操作必触发
5. 提示交互：弹窗文案、关闭方式、附加入口

## 查询报表类

适用：物料钢网、库存、报工等查询报表。

1. 筛选区：每个筛选项的数据源、多选 / 单选、默认值
2. 表格属性：是否可编辑、是否支持新增
3. 字段取值：每个字段的来源表、计算逻辑、显示格式
4. 排序分页：排序规则、分页功能
5. 导出：所见即所得、筛选后导出

## 多级拆分数据链路与数量守恒类

适用：生产订单分单、工单拆解、多级计划拆分等「父→子→孙」链。

1. 链路生成：各级拆分是否生成正确、父子 id 关联、编号规则
2. 数量守恒：每级子项数量之和 ≤ 父项数量；全部拆完父项剩余=0；再拆需剩余>0
3. 删除回退：删除子级后**父级剩余可拆分/数量是否回补**
4. 撤销恢复：撤销拆分后子级是否删除、父级是否恢复拆分前状态
5. 状态透传：下发/审批/状态沿链是否透传、各节点是否一致
6. 派生字段：剩余可拆分、完工合格数（有子级取子级汇总 / 无子级取最后工序报工）、未完工数（数量-合格、负数按0）用接口/DB 核对

## 导入导出与批量操作类

适用：带导入/导出/批量编辑/批量拆分的功能。

1. 导入模板：表头**必填标记**与需求逐字段核对；日期/金额格式；缺必填、非法值、重复、覆盖/去重、部分成功部分失败
2. 导出：**所见即所得**——字段、数据、日期/数量**显示格式**与页面一致
3. 批量编辑：可批量编辑的**字段范围**、单值或按行、是否受唯一/上限约束
4. 批量拆分/下发：可编辑字段、数量之和约束、部分成功部分失败
5. 导入结果：与 simpleExcel/task/findOne 等任务查询接口的 total/success/failed 一致

## 规则冲突与多规则叠加类

适用：同一条记录可能同时命中多条校验/限制的场景。

1. 构造「状态叠加」：如 既「未拆分」又「已下发」、拆分后同时不可编辑/删除/再拆
2. 判定优先级：删除时命中的是哪条限制；哪个规则先拦截，是否符合预期
3. 规则未写清处标注「需产品确认」，不作为确定缺陷
4. 状态 + 权限叠加：角色权限 + 业务限制同时生效

## 配置与权限矩阵

适用：页签/按钮/数据权限、参数配置项。

1. 页签/菜单名称配置项：默认值、配置后生效、角色可见性
2. 按钮权限：按角色显示/隐藏/禁用（新增/删除/下发/拆分/导入导出）
3. 数据权限：不同角色可见数据范围
4. 参数配置：功能选项（如「显示XX级分单计划」）对各模块的联动影响

## 造数配方

适用：需要多条不同状态基线数据的用例前置。

1. 主数据准备：产品/工艺路线/地点组织/工序与报工等先造好
2. 状态基线：给出如何造出「未拆分/部分拆分/完全拆分/已下发/有工序计划/有报工」等各状态的方法
3. 配方复用：前置条件直接引用配方造出的具体状态，不重复推演
4. 数据清理：本轮造数统一命名，测后删除；清理失败写入报告
