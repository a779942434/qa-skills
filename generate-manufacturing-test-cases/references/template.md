# 通用用例模板

## 文档骨架

```markdown
# 【功能名称】 测试用例
## 用例说明
- 覆盖范围：XXX
- 排除范围：忽略边界值、异常值、性能测试，仅验证主流程功能逻辑
- 依据来源：XXX需求文档 + XXX补充规则

| 用例ID | 测试模块 | 测试点 | 前置条件 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- | --- | --- |
```

## 五层完整示例

「标准功能测试版」完整示例：

| 用例ID | 测试模块 | 测试点 | 前置条件 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- | --- | --- |
| **一、入口校验** | | | | | |
| TC-XX-001 | 入口校验 | 正常状态按钮可用 | 数据满足XX条件 | 查看对应位置按钮 | 按钮正常显示可点击 |
| TC-XX-002 | 入口校验 | 不符合条件按钮禁用 | 数据不满足XX条件 | 查看对应位置按钮 | 按钮置灰不可点击 |
| **二、基础交互** | | | | | |
| TC-XX-003 | 基础交互 | 弹窗正常打开 | 满足前置条件 | 点击按钮 | 弹窗正常打开，字段展示完整 |
| TC-XX-004 | 基础交互 | 取消 / 关闭二次确认 | 已填写数据 | 点击取消 / 关闭 | 弹出二次确认，确认后不生效 |
| **三、核心功能-模式1** | | | | | |
| TC-XX-005 | 核心功能 | 正常操作主流程 | 前置数据齐全 | 按步骤执行操作 | 操作成功，数据符合预期 |
| TC-XX-006 | 核心功能 | 校验不通过拦截 | 缺少必填项 / 不符合规则 | 提交操作 | 系统拦截提示，不生成数据 |
| **四、数据结果校验** | | | | | |
| TC-XX-007 | 数据结果 | 原单数据变更 | 操作执行成功 | 查看原单字段 | 原单对应字段按规则变更 |
| TC-XX-008 | 数据结果 | 新单字段取值 | 操作执行成功 | 查看新单字段 | 字段取值符合需求规则 |
| **五、跨模块联动** | | | | | |
| TC-XX-009 | 联动校验 | 关联模块数据同步 | 操作执行成功 | 查看关联模块 | 关联模块数据同步更新 |

## 使用要点

- 套用时把 `XX` 替换为功能模块缩写，如排产 `SP`、ECN 审核 `EC`、技能校验 `SK`、拆单 `CD`
- 一条用例只测一个测试点；同一规则出现多次时描述保持一致
- 开发自测版在此基础上删减纯 UI 交互用例、合并同类校验，但保留主流程与数据变更结果
