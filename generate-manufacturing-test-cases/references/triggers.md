# 需求原文逐句纳管触发清单

> 时机：**需求点化之后、写用例之前**（见 SKILL.md 使用流程第 3 步）。
> 用法：把需求原文**逐句**过一遍下表 → 每个命中信号产出**待判定项** → 再判「需求是否表达」：
> 表达了 → 落成需求点 R-xx + 用例；未表达 → 进「排除范围 / 需求未定义」，**不得脑补**（守「需求边界优先」）。
> 本清单只负责把该想到的摆上桌，不替你决定需求。

**为什么需要**：`scenarios.md` 按**业务场景**索引起步（先判这是哪类场景，漏判=整片漏用例）；
本清单按**需求句子结构**索引，扫原文即命中，不依赖场景判断。二者配合：先逐句扫 → 再按场景补全。

## 1 数量 / 合计 / 守恒
| 信号 | 必判项 |
|---|---|
| 合计 / 总和 / 之和 / 总计 | 分项相加 = 合计；逐级守恒 |
| ≤ / 不超过 / 上限 / 最多 | 恰等、超 1 单位、超精度 三条边界 |
| >0 / 至少 / 不小于 | 0、负值、小数位 |
| 剩余 / 待… / 可推 | 计算口径 + 消费后重算 |
| 每个 / 逐组 / 各… | 逐组独立校验 vs 总体校验，口径写死 |

## 2 顺序 / 依赖 / 优先级
| 信号 | 必判项 |
|---|---|
| 按顺序 / 依次 / 只能前面的 | 顺序是否强校验 + 乱序提示文案 |
| 紧前 / 紧后 / 之前 / 之后 | 前置未满足 → 拦截 + 文案 |
| 优先级 / 优先 / 排在前 | 多命中时的判定优先级 |

## 3 撤销 / 取消 / 删除 / 回退
| 信号 | 必判项 |
|---|---|
| 撤销 / 取消 / 回退 / 还原 | 子级是否消失、数量是否回补、父级是否恢复、二次确认文案 |
| 删除 | 删除前置校验 + 关联数据影响 |
| 同步消失 / 同步取消 | 联动删除范围 |

## 4 多值 / 拼接 / 多选
| 信号 | 必判项 |
|---|---|
| 拼接 / 用,隔开 / 多个 | 多值完整性、增删后重算、空值占位 |
| 可多选 / 多选 | 控件能力**行为判定**（连选两个看是否都保留），不靠 DOM 猜 |
| 含该值即展示 / 只要…就 | 其一命中即返回 |

## 5 默认 / 记忆 / 配置
| 信号 | 必判项 |
|---|---|
| 默认 / 默认值 | 默认值正确 + 可否修改 + 清空后行为 |
| 记住 / 记忆 / 上次选择 | 持久化生效范围（账号/组织/设备切换后） |
| 可配置 / 支持维护 / 参数配置 | 配置入口 + 配置后生效 + **不配置时行为** |
| 固定 / 写死 / 固定天数 | **是否可配置**（未写"可配置"即写死） |
| 自动生成 / 按编码规则 | 规则来源 + 重复校验 + 规则未配置时的表现 |

## 6 校验 / 拦截 / 提示
| 信号 | 必判项 |
|---|---|
| 否则报错 / 提示"…" | 触发条件 + 提示**原文文案** + 拦截后数据不变 |
| 不可 / 不允许 / 禁止 | 触发条件 + 拦截方式（置灰 or 报错，按需求写） |
| 若…则… | 条件两侧各一条 |
| 必须 / 必填 | 留空拦截 + 提示定位 |

## 7 状态 / 流转 / 叠加
| 信号 | 必判项 |
|---|---|
| 状态 / 自动更新 / 回退 | 每个状态值一条 + 流转触发 |
| 已X不可Y / 已…则不能… | 状态+行为叠加，构造同时命中多条限制 |
| 未审核 / 已审核 | 审核状态对可操作项的影响 |

## 8 字段取值 / 来源 / 联动
| 信号 | 必判项 |
|---|---|
| 来源 / 带出 / 随… | 取值来源正确 + 源变更后是否同步 |
| 同步 / 联动 / 影响 | 跨模块数据一致，**接口/DB 核对** |
| 单位 / kg / 小数位 | 单位换算 + 小数位 + 超精度 |
| 类型A / 类型B（生产订单/洗炉计划） | **按类型逐条对照**（每字段对 A、对 B 各是什么） |

## 9 权限 / 入口 / 资源
| 信号 | 必判项 |
|---|---|
| 资源编码 / 权限 | 按钮可见性 + 可用性（无权限账号） |
| 入口 / 菜单路径 | 可达性（直达 URL；被重定向=前置没做） |

## 10 展示 / 格式 / 配置项
| 信号 | 必判项 |
|---|---|
| 只显示数据 / 不显示字段名 | 展示形态 |
| 颜色 / 红 / 绿 / 标识 | 触发条件 + 颜色/文案 |
| 小齿轮 / 表格显示配置 / 列显示 | 配置默认 + 配置后生效 |
| 收缩 / 展开 / 收起 | 交互行为 + 状态记忆 |

## 收尾：扫描台账
逐句扫描后在用例文档附**扫描台账**（三列：命中信号 / 原文出处 / 处置），
处置 ∈ {落 R-xx, 已排除+理由, 需求未定义}，**不允许空处置**——空处置 = 没判 = 可能漏。
